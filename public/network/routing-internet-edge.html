Static route, OSPF, NAT, DHCP, DNS và gateway

Hiểu traffic đi từ VLAN nội bộ ra Internet hoặc sang site khác như thế nào.

Khái niệm

Routing là gì?

Quá trình chọn đường đi cho packet giữa các subnet khác nhau.

Static route là gì?

Route cấu hình thủ công, phù hợp mạng nhỏ hoặc default route ra Internet.

OSPF là gì?

Giao thức routing động giúp router/firewall trao đổi route trong mạng nhiều router.

NAT là gì?

Chuyển IP private sang IP public để user đi Internet hoặc publish dịch vụ nội bộ.

Checklist học

  • Đọc routing table.
  • Cấu hình static route.
  • Hiểu outbound NAT/PAT.
  • Hiểu port forwarding/DNAT.
  • Cấu hình DHCP scope và DNS option.
  • Dùng traceroute xác định packet dừng ở đâu.

Lab

  • DHCP cấp sai gateway và cách phát hiện.
