MikroTik Small Business Edge

RouterOS cho văn phòng nhỏ: DHCP, NAT, firewall filter, VLAN và VPN remote.

Topology

Internet Cloud → MikroTik CHR → Switch → VLAN User/Guest/Server.

Mục tiêu

  • Cấu hình IP WAN/LAN.
  • DHCP server cho VLAN user.
  • NAT masquerade ra Internet.
  • Firewall filter cơ bản.
  • Bridge VLAN filtering.
  • VPN remote cơ bản.

Checklist kiểm tra

  • Client nhận DHCP.
  • Route default hoạt động.
  • NAT ra Internet.
  • Guest không truy cập Server VLAN.
  • Export config sau lab.

Bài tập

  • Chặn ping từ Guest sang LAN.
  • Giới hạn management chỉ từ admin subnet.
  • Viết rule comment rõ mục đích.
