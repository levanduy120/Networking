FortiGate Branch Office Firewall

Dựng FortiGate làm thiết bị edge cho chi nhánh: VLAN, policy, NAT và VPN site-to-site.

Topology đề xuất

Internet Cloud → FortiGate → Core Switch → VLAN User/Server/Guest. Thêm một FortiGate remote để dựng VPN site-to-site.

Thiết bị trong EVE-NG

  • FortiGate VM.
  • 1 switch L2/L3.
  • 2 Linux PC test user/server.
  • Cloud/ NAT node giả lập Internet.

Mục tiêu cấu hình

  • Tạo interface WAN/LAN và VLAN sub-interface.
  • Default route ra Internet.
  • Policy LAN to WAN và NAT outbound.
  • Policy Guest chỉ ra Internet.
  • VPN site-to-site cơ bản giữa 2 FortiGate.

Checklist kiểm tra

  • User lấy đúng IP theo VLAN.
  • User ping gateway VLAN.
  • User ra Internet qua NAT.
  • Guest không truy cập Server VLAN.
  • VPN phase 1/phase 2 up.
  • Đọc log allow/deny đúng policy.

Bài tập mở rộng

  • Thêm rule chỉ cho phép DNS/HTTP/HTTPS.
  • Backup config trước và sau khi đổi policy.
  • Viết sơ đồ IP plan cho toàn lab.
