Palo Alto Security Policy & NAT

Lab tập trung vào zone, interface, security policy, NAT và traffic log.

Topology

Untrust Cloud → Palo Alto VM → Trust LAN/DMZ. Một web server trong DMZ để test NAT publish.

Mục tiêu

  • Tạo zone Trust, Untrust, DMZ.
  • Gán interface và virtual router.
  • Tạo security policy Trust to Untrust.
  • Outbound NAT cho user.
  • DNAT publish web server DMZ.
  • Đọc traffic log để debug deny.

Checklist kiểm tra

  • Commit config thành công.
  • User ping gateway.
  • Traffic HTTP/HTTPS đi đúng rule.
  • Log hiển thị application/service.
  • Rule deny có lý do rõ ràng.

Bài tập

  • Chỉ allow web, deny các service khác.
  • Tạo rule DMZ publish có source hạn chế.
  • Export screenshot log làm tài liệu lab.
