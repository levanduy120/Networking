1. TỔNG QUAN HỆ THỐNG

1.1 Mô Tả Hệ Thống

Duy Network IT Helpdesk là hệ thống hỗ trợ kỹ thuật trực tuyến, cho phép khách hàng gửi yêu cầu hỗ trợ IT và theo dõi trạng thái xử lý. Hệ thống được triển khai trên nền tảng đám mây Railway, có thể truy cập 24/7 từ bất kỳ đâu.

Thông tin Chi tiết
URL chính thức [ĐIỀN URL SAU KHI DEPLOY]
URL admin [URL]/admin
Nền tảng cloud Railway (railway.app)
Repository [ĐIỀN GITHUB REPO URL]
Branch production main
Múi giờ UTC+7 (Việt Nam)

1.2 Kiến Trúc Kỹ Thuật

Lớp Công nghệ Phiên bản Vai trò
Runtime Node.js 20 LTS Chạy server-side JavaScript
Web Framework Express.js 4.18.2 Xử lý HTTP requests, routing
Database SQLite3 5.1.6 Lưu trữ ticket, người dùng, dịch vụ
Frontend HTML5 + CSS3 + Vanilla JS — Giao diện người dùng và admin
Cloud Platform Railway — Hosting, CI/CD, Volume, Domain
Lưu ý về Database: SQLite lưu dữ liệu dưới dạng file data/helpdesk.db. Trên Railway, file này được lưu vào Persistent Volume tại mount path /app/data để đảm bảo dữ liệu không bị mất khi redeploy.

1.3 Tính Năng Chính

Dành cho khách hàng (Public)

  • Xem danh sách dịch vụ IT hỗ trợ (10 loại dịch vụ)
  • Tạo yêu cầu hỗ trợ (ticket) với thông tin liên hệ và mô tả sự cố
  • Nhận mã ticket tự động (định dạng TK + timestamp)
  • Tra cứu trạng thái ticket bằng mã ticket

Dành cho quản trị viên (Admin)

  • Đăng nhập vào trang quản trị bảo mật
  • Xem toàn bộ danh sách ticket với thông tin chi tiết
  • Cập nhật trạng thái ticket: Open → In Progress → Closed
  • Xóa ticket đã xử lý
  • Lọc và tìm kiếm ticket

4. HƯỚNG DẪN SỬ DỤNG ADMIN

4.1 Đăng Nhập Hệ Thống

  1. Truy cập: https://it-helpdesk-production.up.railway.app/admin (hoặc https://helpdesk.network.id.vn/admin khi gắn domain)
  2. Nhập Username: admin (hoặc admin1-5)
  3. Nhập Password: Xem bảng tài khoản ở trên
  4. Click Đăng Nhập
  5. Hệ thống lưu token trong localStorage — không cần đăng nhập lại khi đóng tab
Lưu ý bảo mật: Token đăng nhập được lưu trong trình duyệt (localStorage). Khi cần đăng xuất, xóa cache trình duyệt hoặc mở tab ẩn danh.

4.2 Quản Lý Ticket

Xem danh sách ticket

Sau khi đăng nhập, trang admin hiển thị toàn bộ ticket mới nhất lên đầu. Mỗi ticket hiển thị:

  • Mã ticket (TK + timestamp)
  • Tên khách hàng, email, số điện thoại
  • Dịch vụ yêu cầu
  • Tiêu đề và mô tả sự cố
  • Độ ưu tiên và trạng thái hiện tại
  • Thời gian tạo

Cập nhật trạng thái ticket

  1. Tìm ticket cần xử lý
  2. Click dropdown trạng thái
  3. Chọn trạng thái mới
  4. Hệ thống tự động lưu và cập nhật thời gian

Luồng trạng thái ticket

Trạng thái Ý nghĩa Hành động tiếp theo
Open Ticket mới chưa xử lý Tiếp nhận → chuyển sang In Progress
In Progress Đang được xử lý Sau khi xong → chuyển sang Closed
Closed Đã giải quyết xong Có thể xóa để dọn dẹp

4.3 Phân Loại Ưu Tiên

Mức độ Ý nghĩa Thời gian phản hồi đề xuất
High Sự cố nghiêm trọng, ảnh hưởng nhiều người Trong vòng 1-2 giờ
Medium Sự cố ảnh hưởng một phần, có thể tiếp tục làm việc Trong ngày làm việc
Low Yêu cầu không gấp, cải tiến hoặc tư vấn Trong vòng 2-3 ngày

6.2 Backup Dữ Liệu

Backup thủ công từ Railway

Railway Dashboard → Project → Service → Tab Terminal, chạy:

# Xem file database ls -la data/ # Hiển thị toàn bộ dữ liệu tickets ra màn hình node -e " const db = require('./src/db/database'); db.all('SELECT * FROM tickets', (err, rows) => { console.log(JSON.stringify(rows, null, 2)); process.exit(0); });"

Để download file database, dùng Railway CLI trên máy tính:

# Cài Railway CLI (1 lần) npm install -g @railway/cli # Đăng nhập railway login # Download database railway run -- cat data/helpdesk.db > backup_$(date +%Y%m%d).db

Lịch backup đề xuất

  • Backup hàng tuần vào thứ 6 cuối ngày
  • Backup trước mỗi lần cập nhật code
  • Lưu backup tối thiểu 4 tuần gần nhất

6.3 Cập Nhật Code Mới

Railway tự động deploy khi push code lên GitHub. Quy trình:

  1. Chỉnh sửa code trên máy tính tại d:\claude-agent\it-helpdesk\
  2. Mở PowerShell, chạy:
    cd d:\claude-agent\it-helpdesk git add . git commit -m "Mô tả thay đổi" git push origin main
  3. Railway tự detect push mới và bắt đầu build lại (~2 phút)
  4. Kiểm tra Railway Dashboard → Deployments để theo dõi tiến trình
  5. Sau khi deploy xong, kiểm tra website hoạt động bình thường
Lưu ý: Trong thời gian Railway deploy (~2 phút), website có thể bị gián đoạn ngắn. Nên deploy vào giờ ít traffic (buổi tối hoặc sáng sớm).

9. HƯỚ NG DẪN GẮN DOMAIN network.id.vn

Hiện tại website chạy trên URL Railway mặc định: https://it-helpdesk-production.up.railway.app
Bạn có domain network.id.vn — hãy gắn nó vào Railway để có URL dễ nhớ: https://helpdesk.network.id.vn

9.1 Bước 1 — Cấu Hình Domain Trên Railway

  1. Vào Railway Dashboard → Project → Service it-helpdesk
  2. Tab Settings → Tìm mục Networking
  3. Click Add Custom Domain
  4. Nhập: helpdesk.network.id.vn
  5. Click Add
  6. Railway sẽ hiện DNS Record cần thêm

9.2 Bước 2 — Cấu Hình DNS Tại Nhà Cung Cấp Domain

Sau khi thêm domain trên Railway, bạn sẽ thấy 1 record CNAME:

Type: CNAME Name: helpdesk Value: cname.railway.app (hoặc similar) TTL: 3600

Vào nhà cung cấp domain network.id.vn:

  1. Đăng nhập DNS manager (cPanel, Plesk, hosting control panel...)
  2. Tìm mục DNS Records hoặc Zone Editor
  3. Thêm record CNAME với thông tin Railway cấp:
Trường Giá trị Ví dụ
Type CNAME CNAME
Name / Subdomain helpdesk helpdesk (để trỏ helpdesk.network.id.vn)
Points to / Target / Value [Giá trị từ Railway] cname.railway.app (hoặc tên Railway cấp)
TTL 3600 3600 (1 giờ)

9.3 Bước 3 — Đợi DNS Propagate & Kiểm Tra

Sau khi thêm DNS record, DNS sẽ cần 5-30 phút để propagate.

  1. Truy cập https://dnschecker.org
  2. Nhập: helpdesk.network.id.vn
  3. Chờ tới khi tất cả region hiện IP/CNAME của Railway
  4. Thử truy cập: https://helpdesk.network.id.vn → nếu thấy website = thành công!
✅ Xong! Website sẽ tự động có SSL certificate miễn phí từ Railway. Mọi người giờ có thể truy cập: https://helpdesk.network.id.vn

9.4 Troubleshoot Domain

Vấn đề Nguyên nhân Giải pháp
Domain không vào được DNS chưa propagate hoặc sai record 1. Kiểm tra https://dnschecker.org
2. Xác nhận CNAME record đúng ở DNS manager
3. Chờ 30 phút nếu vừa thêm
SSL certificate error Railway chưa phát SSL cho domain mới 1. Đợi 5 phút sau khi DNS trỏ đúng
2. Railway tự động cấp SSL
3. Reload browser nếu vẫn báo lỗi
Domain trỏ nhưng trang không tải Railway service bị dừng hoặc build fail 1. Railway Dashboard → Kiểm tra service status
2. Xem Logs để tìm lỗi
3. Click Redeploy nếu cần
